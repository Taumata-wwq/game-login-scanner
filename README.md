# 游戏扫码器

一个**多游戏登录二维码扫码器**（仅支持 Windows 10+）：自动识别游戏登录界面的二维码，
用已登录的账号完成确认，免手动输号。

## 支持的游戏

| 厂商 | 游戏 | 登录渠道 |
| --- | --- | --- |
| 米哈游 | 崩坏3 / 崩坏：星穹铁道 / 原神 / 绝区零 | 官服（米游社）/ B 服（Bilibili） |
| 鹰角 | 明日方舟：终末地 / 明日方舟 | 鹰角账号 |

同一米游社 / B 站账号可登录米哈游全系游戏；账号按游戏独立存储与激活。

## 功能

- **多账号管理**：每个渠道可保存多个账号，支持备注、拖拽排序、一键切换与删除。
- **多种登录方式**：二维码 / 短信验证码 / 账号密码（触发人机验证时弹出独立验证窗口）。
- **扫码进游戏**：点击「开始扫码」，自动识别屏幕上（或剪贴板里）的游戏登录码并确认登录；
  2 分钟内成功上限 10 次（防风控）。
- **自定义扫描范围**：主界面实时预览屏幕，滚轮缩放、拖拽平移，可视范围即扫描范围。
- **实用选项**：启动自动登录上次账号、窗口置顶、成功后自动退出 / 清空剪贴板、日志查看。
- **直播抢码**：账号区输入 **B站直播间号**，预览自动切换为**超低延迟直播画面**
  （http-flv 边下边解，延迟稳定在 0.4 秒内，远低于浏览器播放），支持与屏幕预览相同的
  拖拽缩放；点击「开始扫码」即对直播画面识别游戏登录码并自动确认。

## 使用说明

1. **选择游戏**：点击标题栏游戏名。
2. **登录账号**：点击「添加账号」，选择渠道与登录方式，登录后自动设为当前账号。
3. **切换 / 删除账号**：点击账号行切换当前账号；悬停账号行点「✕」删除；双击行编辑备注。
4. **扫码进游戏**：游戏停在登录界面出现二维码后，点「开始扫码」即可自动识别并确认，
   按设置可在成功后清空剪贴板 / 自动退出。
5. **直播抢码**：在账号区右侧输入 B站直播间号，预览与扫码自动切换到直播画面；
   清空输入框即恢复屏幕预览。可视视口即扫描范围（与屏幕模式一致）。
6. **选项 / 日志**：标题栏图标打开弹窗（启动自动登录、窗口置顶、成功后动作、日志清空）。

## 直播抢码说明

- **低延迟**：绕过浏览器播放链路，直接拉取 http-flv 流边下边解（openh264 解码）。
  内置**追帧机制**——以流时间戳对比到达墙钟检测积压，落后超阈值即丢弃至下一关键帧，
  把延迟稳定压在 0.4 秒内，长跑不漂移。
- **自适应清晰度**：若解码吞吐跟不上高码率流，自动逐级降低清晰度（原画→高清→标清→流畅），
  扫码场景无需高清。已是最低档仍不足时，追帧继续维持低延迟。
- **多节点容错**：自动在多个 CDN 节点间轮换，临时 404 / 慢流自动切换重连。
- 仅支持 **B站** 直播间；未开播的房间会即时提示。

## 配置与数据

```
%APPDATA%\游戏扫码器\config.json
%APPDATA%\游戏扫码器\game-login-scanner.log
```

> **全程不输入、不存储账号密码**，仅保存登录令牌（DPAPI 加密落盘，绑定当前用户）。
> 日志超过 2 MB 自动轮转为 `.old`。

## 环境要求与构建

- Windows 10 及以上（需 WebView2 运行时，Win11 已内置）。
- 自行构建：安装 [Rust](https://rustup.rs/) 后在 `src-tauri` 目录执行 `cargo run`（调试运行）
  或 `cargo build --release`（产物在 `target\release\game-login-scanner.exe`，约 5 MB）。

## 注意事项

- 本工具仅用于登录本人游戏账号，请勿用于非授权用途。
- 服务端限流提示（如「操作过于频繁」）为正常防护，稍等片刻重试即可。
- 二维码识别受截图清晰度影响，尽量保证游戏内二维码清晰、无遮挡。
