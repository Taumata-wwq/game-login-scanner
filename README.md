# 游戏扫码器

一个 Windows 上的小工具：游戏登录界面出现二维码时，点一下就能用你已登录的账号自动完成扫码确认，不用再拿手机对着屏幕扫（也不用手输账号）。

支持的游戏：

| 厂商 | 游戏 | 登录渠道 |
| --- | --- | --- |
| 米哈游 | 崩坏3 / 崩坏：星穹铁道 / 原神 / 绝区零 | 官服（米游社）/ B 服（Bilibili） |
| 鹰角 | 明日方舟：终末地 / 明日方舟 | 鹰角账号 |

同一个米游社 / B 站账号可以在米哈游全系游戏里用；账号按游戏分开存、分开选。

---

## 怎么用

**1. 选游戏** — 点标题栏上的游戏名，选你要登录的那个（按厂商分组）。

**2. 登录账号** — 点「添加账号」，选渠道（官服 / B 服 / 鹰角）再选登录方式（二维码 / 短信验证码 / 账号密码）。登录成功的账号会自动存下来并设为当前账号；同一渠道可以存多个账号。

碰上一人机验证（极验）时会弹一个小窗口让你划一下，划完自动继续。

**3. 切账号 / 删账号** — 点账号行就切换成它；鼠标移到行上点「✕」删除；双击行可以改备注名和备注（比如「小号」「朋友号」），拖拽能调整顺序。想加新账号就点列表最下面那个虚线按钮。

**4. 扫码进游戏** — 游戏停在登录界面、屏幕上出现二维码之后，点「开始扫码」。工具会先看一眼剪贴板，没有就去屏幕上找，认出二维码就用当前账号自动确认。2 分钟内最多成功 10 次（服务端有这个限制，属于正常防护）。

**5. 直播抢码** — 账号区右边有个输入框，填 B站直播间号（比如 `6`），预览画面和扫码就会自动切到那个直播间——抢码时不用一直盯着游戏登录界面，让游戏二维码出现在直播画面里就行。把输入框清空就切回屏幕预览。直播画面同样能滚轮缩放、拖拽平移，窗口里看到的那块就是扫码范围。直播间没开播会直接提示。

**6. 设置与日志** — 点标题栏的图标打开弹窗，里面是：登入名、启动时自动开启扫码、窗口置顶、扫码成功后自动退出、显示区域帧率（30 / 60 / 120），下面是运行日志（可清空）。

## 关于延迟

直播抢码走的是 http-flv 直播流，边下边解，不经过浏览器播放那一套，延迟一般能压到 0.4 秒左右。如果电脑解码跟不上高码率的流，会自动降一档清晰度（原画 → 高清 → 标清 → 流畅），扫码对清晰度要求不高；CDN 节点抽风时也会自动换节点重连。目前只支持 B站直播间。

## 数据放在哪

```
%APPDATA%\游戏扫码器\config.json          配置与账号
%APPDATA%\游戏扫码器\game-login-scanner.log   运行日志（超 2MB 自动转 .old）
```

工具不输入也不存你的账号密码，只保存登录令牌，而且是用 Windows 自带的加密（DPAPI，绑定当前用户）写盘的——换台电脑或换个用户就解不开了。

## 自己编译

需要 Windows 10 及以上（WebView2 运行时，Win11 自带），以及 [Rust](https://rustup.rs/)：

```powershell
cd src-tauri
cargo run                 # 调试运行
cargo build --release     # 出包：target\release\game-login-scanner.exe（约 4.6 MB）
```

代码结构（想改代码的话看这里）：

```
src/index.html          主界面（原生 HTML/CSS/JS，无前端构建链）
src/verify.html         人机验证窗口
src-tauri/src/
  lib.rs                Tauri 命令接线与运行时状态
  scan.rs               扫码主流程（剪贴板 → 屏幕/直播帧 → 确认登录）
  live.rs               直播流捕获（B站接口解析 → FLV 解复用 → openh264 解码）
  qr.rs                 二维码识别（rqrr 为主 + zedbar 兜底）与二维码生成
  screenshot.rs         GDI 截屏兜底
  duplication.rs        DXGI 桌面复制（低开销取帧）
  clipboard.rs          剪贴板读图
  sdk/                  各渠道登录协议（mihoyo / official / bili / hypergryph / cred_login）
  config.rs / crypto.rs / http.rs / constants.rs
```

测试：`cargo test`；真实网络探针（需手动跑）：`cargo test --test probe -- --ignored --nocapture`。

## 注意

- 只用来登录自己的账号，别拿去做别的。
- 看到「操作过于频繁」之类提示是服务端的正常限流，等一会儿再试。
- 二维码识别效果跟画面清晰度有关，尽量别让码被遮挡或糊掉。
