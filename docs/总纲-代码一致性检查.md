### 三、新发现的待办（未在本轮处理）

- **死配置 `ScanChannel` / `AppConfig::scan_channel`**：
  - `src-tauri/src/config.rs` 定义了 `ScanChannel` 枚举与 `scan_channel` 字段，
    但 `lib.rs` / `scan.rs` / 前端均**未读取**，`ScanChannel::fixed()` 从未被调用。
  - 属于设计早期「指定渠道」方案的残留；当前实现是「按已登录账号自动路由」，无需该字段。
  - **建议**：从 `AppConfig` 移除（用 `#[serde(skip)]` 保留读取兼容），或明确其未来用途。
  - 风险：低（仅冗余字段，不影响功能）。

- **`channel` 字段的迁移兼容**：`unit.rs::config_accepts_partial_json` 里有
  `{"channel":"official", ...}` 的用例，注释说明该旧字段被忽略；与 `scan_channel`
  无冲突，保留即可。

## 检查 2026-10-02 · 第二轮（clippy 整改）

### 一、核查方法
跑 `cargo clippy --all-targets -- -D warnings`（与 CI 一致），逐条修复。

### 二、修复清单（11 处）

| 文件 | 问题 | 修复 |
| --- | --- | --- |
| `lib.rs::save_config` | `let_unit_value`（`save()` 返回 `()` 却绑给变量） | 去掉 `let saved`，直接 `?;`，返回 `Ok(())` |

| `lib.rs::capture_preview` | `manual_clamp` | `.min(300).max(1)` → `.clamp(1, 300)` |
| `config.rs::save` | `io_other_error` | `Error::new(ErrorKind::Other, e)` → `Error::other(e)` |
| `qr.rs::rgba_to_rgb` | `chunks_exact` 常量块大小 | 改用 `as_chunks::<4>()` |
| `qr.rs::decode_once` | 同上（`as_chunks::<3>()`） | 改用 `as_chunks` |
| `scan.rs` 模块文档 | `doc_lazy_continuation`（列表后续行未缩进/无空行） | 加空行 |
| `password.rs` 模块文档 | 同上 | 加空行 |
| `scan.rs::run_scan` | `too_many_arguments`（8/7） | 打包为 `ScanArgs` 结构体 |
| `scan.rs::run_scan` | `clone_on_copy`（`Option<(i32,i32,i32,i32)>` 是 Copy） | 改 `.clone()` → `*` 解引用拷贝 |
| `tests/smoke.rs` | `assertions_on_constants`（`assert!(true)`） | 改为构造默认配置并断言 `interval_ms` |
| `tests/unit.rs` | `unnecessary_min_or_max`（`200.min(302)`） | 直接写 `200` |
| `tests/unit.rs` | `field_reassign_with_default` | 改用结构体更新语法 `AppConfig { interval_ms: 1, ..Default::default() }` |

## 附：一致性检查的常规清单（后续核查可复用）

1. **命令数**：`grep -c "#\[tauri::command\]" lib.rs` 与总纲第 2 节一致？
2. **模块表**：每个 `.rs` 文件的职责描述是否仍准确（尤其新增能力）？
3. **`AppState` 字段**：总纲第 2 节数据流是否列全？
4. **安全基线**：加密字段范围、CSP 内容、节流阈值是否与代码一致？
5. **缺陷清单**：状态标记（✅/⏳/⚠️）是否反映最新代码？
6. **测试数**：总纲/本文件提到的测试数与 `cargo test` 实际一致？
7. **死代码/死配置**：`cargo clippy` + 人工 grep 是否发现未使用项？
8. **版本号**：`Cargo.toml` / `package.json` / `tauri.conf.json` 三处一致？
